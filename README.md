Cüzdanım 👛 - Kişisel Finans ve Bütçe Takip Uygulaması

Cüzdanım, kullanıcıların günlük harcamalarını, aylık sabit giderlerini ve birikim hedeflerini tek bir ekrandan kolayca yönetebilmelerini sağlayan, modern ve mobil uyumlu (Mobile-First) bir React uygulamasıdır.

Bu proje, modern web geliştirme pratiklerini ve kullanıcı deneyimini (UX) ön planda tutarak sıfırdan geliştirilmiştir. Herhangi bir arka uç (backend) veya veritabanı bağlantısı gerektirmeden, tüm verileri tarayıcının yerel hafızasında (Local Storage) güvenli bir şekilde saklar.

🚀 Öne Çıkan Özellikler

📱 PWA (Progressive Web App) Desteği: Tarayıcı üzerinden yerel bir mobil uygulama gibi telefona veya masaüstüne kurulabilir.

🌓 Koyu ve Açık Tema: Göz yormayan, pürüzsüz geçişli tam ekran Dark/Light Mode desteği.

🎯 Hedef Kumbarası (Oyunlaştırma): Özel birikim hedefleri oluşturma ve yatay kaydırılabilir (scroll-snap) kartlarla ilerleme takibi.

🔄 Otomatik Sabit Gider Yönetimi: Ayın belirli günlerinde bütçeden otomatik olarak düşen abonelik ve fatura yöneticisi.

📊 Gelişmiş İstatistikler: Recharts entegrasyonu ile harcamaların kategori bazlı interaktif pasta grafiği.

📥 CSV Dışa Aktarma: Tek tıkla tüm işlem geçmişini Excel (CSV) formatında bilgisayara/telefona indirme (UTF-8 BOM desteği ile Türkçe karakter uyumlu).

🔍 Gelişmiş Filtreleme ve Sıralama: Harcamaları tarihe, fiyata, isme ve kategoriye göre çoklu filtreleme/sıralama özelliği.

✨ Akıcı UX Animasyonları: Sayfa geçişlerinde ve liste güncellemelerinde saf CSS ile yapılmış yumuşak animasyonlar.

💾 Kalıcı Veri: Kapatıp açıldığında bile son kalınan yeri, temayı ve tüm finansal verileri hatırlayan mimari.

🛠️ Kullanılan Teknolojiler

Frontend Kütüphanesi: React.js (Hooks: useState, useEffect)

Proje Paketleyici: Vite (Hızlı geliştirme ve derleme)

Stil & Tasarım: Saf CSS (Flexbox, Grid, CSS Animasyonları)

Veri Görselleştirme: Recharts (Pasta grafikler için)

İkonlar: React Icons

Veri Saklama: Tarayıcı API (localStorage)

💻 Yerel Ortamda Çalıştırma (Kurulum)

Projeyi kendi bilgisayarınızda çalıştırmak için aşağıdaki adımları izleyebilirsiniz:

Projeyi Klonlayın:

git clone https://github.com/KULLANICI_ADINIZ/cuzdanim.git


Proje Klasörüne Girin:

cd cuzdanim


Gerekli Paketleri Yükleyin:

npm install


Geliştirici Sunucusunu Başlatın:

npm run dev


Terminalde beliren http://localhost:5173/ adresine tıklayarak uygulamayı tarayıcınızda açabilirsiniz.
